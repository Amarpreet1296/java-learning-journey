# 🏏 Cricketer Stats Manager

A simple Java console application to practice the **Java Collection Framework**
using real-world cricket player data.

---

## 📌 Project Overview

This project manages a list of cricketers and allows you to perform operations like:

* Sorting players by runs or age
* Filtering players by role (Batsman, Bowler, etc.)
* Grouping players based on roles
* Finding top performers
* Searching players by name

It is designed as a **learning project** to strengthen understanding of:

* Lists (`ArrayList`)
* Maps (`HashMap`)
* Streams & Lambdas
* Object-Oriented Programming (OOP)

---

## 🛠️ Technologies Used

* Java (JDK 8+)
* Java Collections Framework
* Streams API

---

## 📂 Project Structure

```
Cricketer.java         // Model class
CricketerService.java  // Business logic
Main.java              // Entry point
```

---

## 🚀 Features

* Get top N run scorers
* Filter players by role
* Group players by role
* Calculate average runs
* Search player by name
* Sort players by age

---

## ▶️ How to Run

1. Clone the repository or copy the files
2. Open in your IDE (IntelliJ / VS Code / Eclipse)
3. Compile and run `Main.java`
